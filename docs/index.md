- **실시간 통합 검색**:
    - 키보드의 <kbd>S</kbd>, <kbd>/</kbd>, 또는 <kbd>F</kbd> 키를 누르면 검색창이 활성화됩니다.

- **연도/월별 시계열 아카이브**:
    - 상단 메뉴 탭(`하루치 뉴스정리`, `종목분석`, `낙폭과대`, `주식투자 Q&A`, `인터넷 민심`, `찌라시`, `투자 트랙레코드`)을 클릭하면 좌측 사이드바에 `연도 > 월` 순으로 일관되게 계층화된 아카이브가 제공됩니다.
- **문서 내 목차(TOC) 추적**:
