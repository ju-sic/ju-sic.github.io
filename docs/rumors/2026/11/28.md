## 2. "상하이 데이터센터 블랙웰 칩 발견 → 엔비디아 직접 밀수" 팩트 대조

블룸버그 단독 보도 직후 X.com(조회 187만)과 국내 커뮤니티에서 "<a href="https://highchart-opal.vercel.app/chart/NVDA">엔비디아(NVDA)</a>와 젠슨 황이 중국에 직접 수출통제 칩을 팔아넘겼다"는 단정이 빠르게 번졌다.

<div class="r-versus">
<div class="r-versus__box">
<span class="r-tag r-tag--open">커뮤 주장 · 직접 공모 단정</span>
<p>X.com(<a href="https://x.com/Kalshi_Finance/status/2126326494486032451">시총 2,000억 증발 속보</a> · <a href="https://x.com/BillKristol/status/2126393637106004034">상하이 반입 인용</a>)과 댓글에서 아래 주장이 확산됐다.</p>
<ul>
<li>"앨리스 황과 연계된 상하이 데이터센터에서 블랙웰 칩이 발견됐으므로 엔비디아가 미국 수출통제를 직접 위반했다."</li>
<li>"젠슨 황 CEO가 이를 알고 묵인했거나 공모했으며, 곧 다시 CEO 자리에서 해임될 것이다."</li>
<li>"엔비디아 주가에서 1시간 만에 2,000억 달러가 증발할 만큼 결정적 스모킹 건이 나왔다."</li>
</ul>
</div>
<div class="r-versus__box">
<span class="r-tag r-tag--fact">블룸버그 원문 · 유통 경로 검증 팩트</span>
<p>중국 상하이 내 블랙웰 랙 존재는 대출 서류로 확인된 사실이나, <strong>엔비디아·메가스피드의 직접 유출 증거는 확인되지 않았다.</strong></p>
<ul>
<li>중국 규제 당국에 제출된 대출 담보 서류상 상하이 장강삼각주 데이터센터 프로젝트 참여사 2곳(상하이 숴야오·상하이 커잔)이 <strong>GB300 NVL72 랙</strong>(9,600만 위안 담보)과 <strong>GB200 서버</strong>(9,000만 위안 담보)를 보유한 사실은 블룸버그 보도로 확인됐다.</li>
<li>두 회사가 앨리스 황(전 메가스피드 임원)과 직간접적으로 연결된 것도 보도 내용과 일치한다. 다만 블룸버그가 시리얼 번호를 추적한 결과 GB300 랙은 <strong>대만 기가바이트(Gigabyte) 제조품</strong>으로 확인됐고, 기가바이트는 최초 구매자를 밝히지 않았다.</li>
<li>블룸버그는 기사 본문에서 <strong>메가스피드나 엔비디아가 해당 장비를 직접 중국으로 빼돌렸다는 직접 증거는 찾지 못했으며</strong>, 여러 현지 유통망을 거친 우회 반입 경위는 아직 불명확하다고 명시했다.</li>
</ul>
</div>
</div>

<div class="r-verdict">
<span class="r-verdict__label">정리</span>
<p>상하이 데이터센터에 수출통제 대상인 블랙웰 랙이 반입된 것은 대출 담보 서류로 확인된 팩트다. 다만 대만 제조사 출고 이후 현지 유통망을 거친 밀수 경로가 규명되지 않았고 엔비디아·메가스피드의 직접 유출 증거도 확인되지 않았으므로, '엔비디아 직접 밀수 확정'은 앞선 단정이다.</p>
</div>
