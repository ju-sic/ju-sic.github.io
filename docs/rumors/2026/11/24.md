## 2. "트루먼쇼 작전 · 나스닥 상한 보호 정지 · 3.4M 콜옵션 내부자 거래" 팩트 대조

증시 반전 속도가 워낙 비현실적이다 보니 커뮤니티에서는 백악관 개입과 옵션 대박·거래정지 사실을 하나로 엮어 '짜여진 시세조종 각본'으로 단정하는 글이 급속히 퍼졌다.

<div class="r-versus">
<div class="r-versus__box">
<span class="r-tag r-tag--open">커뮤 주장 · 음모론 비약</span>
<p>스레드(<a href="https://www.threads.com/@happy_tracer/post/DgFq9FUgUBT">원문 1</a> · <a href="https://www.threads.com/@tak_sa_ka/post/DgF1G-Zk6lK">원문 2</a>), 블라인드(<a href="https://www.teamblind.com/kr/post/wyux2pss">원문</a>), X.com(<a href="https://x.com/liquidtrading/status/2124889413172031894">콜옵션 1</a> · <a href="https://x.com/MrMikeInvesting/status/2124869411001545117">콜옵션 2</a> · <a href="https://x.com/unusual_whales/status/2124879052779717042">나스닥 정지</a>)에서 아래 세 주장이 퍼졌다.</p>
<ul>
<li>"젠슨 황 사임 → 폭락 → <a href="https://highchart-opal.vercel.app/chart/ANT">앤트로픽(ANT)</a> 상장 → 복귀는 트럼프·이사회 한패의 트루먼쇼 작전이다."</li>
<li>"금요일 장 마감 직전 누군가 월요일 만기 $160 콜옵션 340만 달러를 사서 3억 1,200만 달러(+9,000%)를 번 것은 명백한 내부자 거래다."</li>
<li>"나스닥이 공매도 세력을 보호하려고 오를 때만 상한 서킷브레이커로 거래를 강제 중단시켰다."</li>
</ul>
</div>
<div class="r-versus__box">
<span class="r-tag r-tag--fact">공식 발표 · 거래소 규정 팩트</span>
<p>트럼프 대통령의 이사회 설득 개입은 본인이 직접 시인한 사실이지만, 나머지 주장은 핵심 사실관계가 다르거나 진위가 확인되지 않았다.</p>
<ul>
<li>트럼프 대통령이 이사회에 직접 전화해 복귀를 성사시켰다고 밝히고 미 의회가 반발한 것은 사실이나, <a href="https://highchart-opal.vercel.app/chart/ANT">앤트로픽(ANT)</a> IPO와 맞물린 시세조종 각본을 뒷받침할 공식 수사 결과는 없다.</li>
<li>$3.4M → $312M 콜옵션 주장은 X.com에서 번져 루벤 가예고 상원의원 등의 SEC 조사 촉구로 이어졌으나, 옵션 흐름 추적 플랫폼(체더플로우 등)에서 동일 블록 체결이 확인되지 않는다는 반박도 제기돼 실제 체결 여부·주체는 미확인 상태다.</li>
<li>23일 상한 정지는 나스닥 본장의 '숏 보호 서킷'이 아니라 <strong>정규장 개장 전 나스닥 100 선물(+7% 가격제한 도달)</strong>의 자동 변동성 완화 장치다. 미국 정규장 지수 서킷브레이커는 하락(-7·-13·-20%)에만 작동한다.</li>
</ul>
</div>
</div>

<div class="r-verdict">
<span class="r-verdict__label">정리</span>
<p>백악관의 기업 인사 개입은 사실이지만, 개장 전 선물 상한 제한을 정규장 공매도 보호로 오해하거나 검증되지 않은 옵션 캡처만으로 시세조종을 단정해서는 안 된다. 미 의회 청문회와 SEC 실제 조사 개시 여부로만 판단해야 한다.</p>
</div>
