## 1. 한·대만·중 주말 증시 대책 타임라인: 발표·준비·집행 구분

주말 사이 아시아 3국이 동시에 증시 안정책을 꺼냈지만, 실제 집행 단계는 나라마다 완전히 달랐다.

<ol class="r-timeline">
<li class="r-timeline__item">
<span class="r-timeline__date">11/21 (토)</span>
<div class="r-timeline__body">
<strong>대만, 5대 공매도 통제 발표 및 국안기금 실매수 확인</strong>
<p>대만 금융당국이 23일 개장부터 전 종목 전일 종가 이하 공매도 금지, 공매도 증거금 150% 상향, 풋워런트 신규 상장 중단을 시행한다고 발표했다. 5,000억 대만달러(약 151.8억 달러) 한도의 국안기금은 이미 시장 매수에 들어갔음을 공식 확인했다.</p>
</div>
</li>
<li class="r-timeline__item">
<span class="r-timeline__date">11/22 (일)</span>
<div class="r-timeline__body">
<strong>한국 F4 "증안펀드 준비 착수" · 중국 신용증거금 완화 발표</strong>
<p>이형일 부총리·한은 총재·금융위원장·금감원장이 F4 회의를 열어 10조 7,600억 원 증안펀드 가동 준비 착수, 24일부터 3개월간 자사주 1일 매수 한도 완화, 불법 공매도 집중 감시를 발표했다. 중국 3대 거래소는 11월 30일 시행 신용증거금 인하(100% → 80%)를 내놨다.</p>
</div>
</li>
<li class="r-timeline__item">
<span class="r-timeline__date">11/23 (월)</span>
<div class="r-timeline__body">
<strong>대만 장중 급반등 vs 한국 코스피 매도 사이드카 발동</strong>
<p>대만 가권지수는 공매도 봉쇄와 국안기금 매수 속에 <a href="https://highchart-opal.vercel.app/chart/TSM">TSMC(TSM)</a> 주도로 장중 저점 대비 1,200p 넘게 반등했다. 반면 한국은 실매수 없는 첫날 오전 코스피 매도 사이드카가 발동되고 코스닥 627선(2024년 계엄 저점)이 뚫렸다.</p>
</div>
</li>
<li class="r-timeline__item">
<span class="r-timeline__date">11/24 (화)</span>
<div class="r-timeline__body">
<strong>한국 상장사 자사주 한도 완화 및 불법 공매도 감시 시행</strong>
<p>22일 발표분 가운데 상장기업 1일 자기주식 매수주문 수량 한도 완화와 금감원·거래소의 불법 공매도 3개월 특별 감시가 화요일 개장부터 실제 적용된다.</p>
</div>
</li>

## 2. "증안펀드 10조 투입 · 자사주 강제 매입 · 공매도 금지" 팩트 대조

커뮤니티에서는 '준비' 발표를 곧바로 '실탄 집행'이나 '공매도 금지'로 오해한 글이 급속히 퍼졌다.

<div class="r-versus">
<div class="r-versus__box">
<span class="r-tag r-tag--fake">커뮤 주장 · 단계 혼동</span>
<p>블라인드(<a href="https://www.teamblind.com/kr/post/eqmdu7td">원문 1</a> · <a href="https://www.teamblind.com/kr/post/y6nsqr50">원문 2</a>)와 스레드(<a href="https://www.threads.com/@engineeronthefield/post/DgC8lPTGFkJ">원문 1</a> · <a href="https://www.threads.com/@jbl_d123/post/DgCDcDAkV50">원문 2</a>)에서 아래 세 주장이 반복됐다.</p>
<ul>
<li>"월요일 개장부터 10조 원 증안펀드 실탄이 즉시 투입된다."</li>
<li>"정부가 <a href="https://highchart-opal.vercel.app/chart/005930">삼성전자(005930)</a>·<a href="https://highchart-opal.vercel.app/chart/000660">SK하이닉스(000660)</a>에 자사주 매입을 사전 협의하거나 강제 압박했다."</li>
<li>"한국도 대만처럼 공매도 전면 금지를 바로 꺼내 들 것이다."</li>
</ul>
</div>
<div class="r-versus__box">
<span class="r-tag r-tag--fact">공식 발표 팩트</span>
<p>이형일 부총리 공식 입장(<a href="https://x.com/leehimofe/status/2124653994207522893">@leehimofe 원문</a>)과 22일 F4 회의 발표의 정확한 단계는 다르다.</p>
<ul>
<li>증안펀드 10조 7,600억 원은 <strong>가동 준비 착수</strong> 단계다. 투입 시점과 규모는 미정이며 2008년(5,150억 원 집행) 이후 실제 매수 사례는 없다.</li>
<li>자사주 대책은 강제 매입이 아니라 상장사의 1일 매수주문 수량 한도를 24일부터 3개월간 풀어주는 <strong>규제 완화</strong>다.</li>
<li>공매도 전면 금지는 포함되지 않았으며, 불법 공매도 3개월 집중 감시만 시행한다.</li>
</ul>
</div>
</div>

<div class="r-verdict">
<span class="r-verdict__label">정리</span>
<p>한국 F4 대책은 '실탄 집행·공매도 봉쇄'가 아니라 '가동 준비·규제 완화·불법 감시'다. 발표 단계를 월요일 갭상승 재료로 착각해 신용 몰빵에 나서는 행위는 위험하다.</p>
</div>
